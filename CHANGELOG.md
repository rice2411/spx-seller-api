## [0.1.0] - 2026-11-13

### Added

- Initial release: seller portal login through headless Chrome (human-solved challenges), account info, wallet balance
  and transactions, shipment list, shipping labels, bulk shipment creation through the portal's Excel import, public
  parcel tracking (`getTracking`, `trackingUrl`).
- Dual ESM + CommonJS build with type definitions, unit tests (Vitest), ESLint + Prettier, CI and release workflows.
